# InvoiceApp.ng Monorepo Architecture

This repository has been migrated from a single Vite SPA to a **pnpm workspace monorepo**. This was done to implement an **"App-First" SSR Architecture** that perfectly balances a heavy, offline-capable application with sub-100ms SEO dominance.

## Project Structure

*   **`apps/web`**: The core InvoiceApp.ng application. Built with Vite and React. It is a heavy, offline-first PWA that handles the invoice editor, dashboards, settings, and complex state management.
*   **`apps/marketing`**: A lightweight Astro + MDX project. This is responsible *only* for rendering the programmatic SEO landing pages (`/templates/*`) and the blog (`/blog/*`). It compiles to static HTML for instant load times and perfect Google Rich Snippet indexing.

## Edge Routing / Rewrites

We use CDN-level routing (defined in `vercel.json`) to serve these two apps under a single domain without compromises:

1.  If a user requests `https://invoiceapp.ng/blog/*` or `https://invoiceapp.ng/templates/*`, the CDN serves the HTML generated by the `apps/marketing` Astro project.
2.  If a user requests `https://invoiceapp.ng/` or any other route, the CDN serves the `apps/web` Vite SPA.

This ensures zero "Flash of Death" for blog readers, while keeping the root domain entirely focused on product conversion and utility.

## Commands

From the root directory, you can run the following `pnpm` commands to manage the workspace:

*   `pnpm install`: Installs dependencies for all projects in the workspace.
*   `pnpm run dev`: Starts the development servers for both `apps/web` and `apps/marketing` in parallel.
*   `pnpm run build`: Builds both applications for production.
*   `pnpm run test`: Runs the Vitest suites inside `apps/web`.

## 2025-03-04 - Command Palette ARIA attributes
**Learning:** Command Palette components (and other custom comboboxes/selects) built from scratch often lack standard ARIA semantic structure. While keyboard navigation might work via custom event listeners, screen readers need explicitly declared relationships (e.g. `role="listbox"` and `role="option"`) in order to properly announce the dynamically updated lists of search results as users use arrow keys to navigate.
**Action:** When implementing or reviewing any Command Palette, Autocomplete, or Select dropdown component, always verify the presence of `role="dialog"` or `role="combobox"` for the container, `role="listbox"` for the list of items, and `role="option"` with `aria-selected` for the interactive choices.

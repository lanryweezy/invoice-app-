## 2024-07-23 - Canva vs Kreathief (InvoiceApp): PDF Export Quality
**Gap:** Canva and professional tools output crisp, vector-based PDFs with selectable text, embedded fonts, and tiny file sizes. Kreathief outputs a compressed 0.8 quality JPEG embedded inside a PDF container. Text is unselectable, blurry upon zooming, and the file size is bloated.
**Root cause:** Architectural/Prioritisation. The codebase uses `html2canvas` to screenshot the DOM and `jsPDF.addImage(imgData, 'JPEG')` to wrap it (`apps/web/App.tsx`, lines 570-583). This is a lazy frontend hack, not a professional rendering engine.
**Proposal:** Rip out `html2canvas`. Replace it with `@react-pdf/renderer` to generate actual vector PDFs from React components, or generate standard HTML and print to PDF via a serverless function.
**Strategic note:** If a professional sends an invoice and their client cannot highlight and copy the bank account number because it is a JPEG, Kreathief looks like a toy, destroying trust instantly.

## 2025-03-02 - Linear vs Kreathief (InvoiceApp): Command Palette Workflow
**Gap:** Linear's command palette serves as the primary navigation and action hub for power users. It exposes every action in the UI, supports complex nested workflows, and executes instantly. Kreathief's Command Palette (`apps/web/components/CommandPaletteProvider.tsx`) is a severely limited 8-item navigation menu masquerading as a command palette. It only routes to other views or triggers basic modals (like 'settings' or 'upgrade').
**Root cause:** Product Vision / Component Limitation. The Command Palette was built as an afterthought rather than a central event bus. It lacks context awareness, nested commands, fuzzy matching across dynamic data (e.g., searching for a specific invoice number or client name), and the ability to execute inline actions (e.g., 'Change status to Paid' without leaving the current view).
**Proposal:** Rebuild the Command Palette using a robust library like `cmdk`. Integrate it with the application's global state so it can index active invoices, clients, and receipts. Add actions like 'Create New Invoice', 'Download PDF', 'Send Email', and 'Mark as Paid' that execute directly from the palette.
**Strategic note:** Power users judge SaaS quality by keyboard navigability. A superficial command palette signals to a Linear/Raycast user that the tool is consumer-grade and not built for speed.

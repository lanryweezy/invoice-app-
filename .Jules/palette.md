## 2024-03-24 - ARIA attributes for custom Command Palettes\n**Learning:** Custom components acting as command palettes or select lists (such as a Cmd+K modal) require specific ARIA roles to be fully accessible by screen readers. The dialog itself needs `role="dialog"` and `aria-modal="true"`. The input should have a clear `aria-label`. Crucially, the list of options must use `role="listbox"` and the individual items need `role="option"` with `aria-selected` to convey state. Without these, screen readers struggle to interpret the component's purpose and state.\n**Action:** Whenever building or reviewing custom comboboxes, command palettes, or select dropdowns, always ensure the `listbox` and `option` roles are applied alongside standard modal ARIA attributes.
